# WÜ Tutorien: Arbeit in Cloud-Sitzungen

Repository für aufwendige Arbeitsschritte der Tutorien Wärmeübertragung (zuerst die unabhängige Prüfung der Kaffee-Aufgabe), die in einer Cloud-Sitzung von Claude Code laufen. Anweisungen für Claude: `CLAUDE.md`. Setup-Skript der Cloud-Umgebung: `setup/umgebung_setup.sh`. Ergebnisse: `ergebnisse/`.

Maßgeblicher Arbeitsstand bleibt der Werkzeugkasten im WÜ-Ordner der Tutoriumsleitung; ein Chat im Projekt „Wärmeübertragung Tutorium“ übernimmt die Ergebnisse von hier.
